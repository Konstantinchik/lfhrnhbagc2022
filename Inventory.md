# Inventory

## Расширяемый инвентарь

Основная сетка инвентаря сохраняет исходное количество столбцов и видимую высоту. Когда свободных ячеек для предмета не остаётся, `DTInventory` добавляет целую строку ячеек внизу сетки и повторяет поиск. Размер `Content` обновляется вместе с числом строк.

Для просмотра расширенной сетки при инициализации создаются `Inventory Viewport`, `Inventory Content`, `ScrollRect` и вертикальный `Scrollbar`. Исходная сетка и отображаемые предметы размещаются внутри `Content`; viewport обрезает всё за пределами исходной видимой области. Loot-сетка и панели экипировки остаются вне прокручиваемого содержимого и не участвуют в поиске места для обычного инвентаря.

Добавленные ячейки получают обычные координаты сетки и регистрируются в общем списке слотов. Благодаря этому существующие проверки размещения, освобождения ячеек и определения координат продолжают работать для новых строк.

При начале перетаскивания предмет переводится непосредственно под объект инвентаря с сохранением мировой позиции. Это позволяет перетаскивать его за пределы маски viewport; при размещении логика drag-and-drop назначает ему родителя целевой ячейки.

## Проверка

- Пользователь подтвердил работу расширяемой сетки и прокрутки в Unity; на предоставленном скриншоте виден вертикальный scrollbar.
- `git diff --check` выполнен при подготовке изменений.
