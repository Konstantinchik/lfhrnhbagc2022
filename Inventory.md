# Inventory

## Расширяемый инвентарь

Основная сетка инвентаря сохраняет исходное количество столбцов и видимую высоту. Когда свободных ячеек для предмета не остаётся, `DTInventory` добавляет целую строку ячеек внизу сетки и повторяет поиск. Размер `Content` обновляется вместе с числом строк.

Для просмотра расширенной сетки при инициализации создаются `Inventory Viewport`, `Inventory Content`, `ScrollRect` и вертикальный `Scrollbar`. Исходная сетка и отображаемые предметы размещаются внутри `Content`; viewport обрезает всё за пределами исходной видимой области. Loot-сетка расширяется независимо: у панели ящика создаются `Loot Viewport`, `Loot Content`, `ScrollRect` и вертикальный scrollbar; при заполнении добавляются строки с прежним числом колонок. Предмет можно перетащить из инвентаря игрока в переполненный ящик: для drop автоматически создаётся следующая строка. Ячейки loot продолжают использовать координаты области `9000+`, поэтому существующий drag/drop и сохранение содержимого ящиков совместимы.

Добавленные ячейки получают координаты своей сетки и регистрируются в общем списке слотов. Благодаря этому существующие проверки размещения, освобождения ячеек и определения координат продолжают работать для новых строк. При загрузке сохранённых предметов с координатами ниже стартовых строк соответствующая сетка сначала достраивается до нужной высоты.

При начале перетаскивания предмет переводится непосредственно под объект инвентаря с сохранением мировой позиции. Это позволяет перетаскивать его за пределы маски viewport; при размещении логика drag-and-drop назначает ему родителя целевой ячейки.

## Проверка

- Пользователь ранее подтвердил работу расширяемой сетки и прокрутки инвентаря игрока в Unity; на предоставленном скриншоте виден вертикальный scrollbar.
- Loot-сетка динамически создаёт строки и прокручивается внутри видимой панели; можно добавлять содержимое сверх исходных 5×5 ячеек.
- **Unity runtime-проверка подтверждена пользователем:** ящик заполнен сверх начального размера, скриншот показывает прокручиваемую сетку и дополнительные предметы в лут-панели.
- При переносе предмета в заполненный ящик drop автоматически ищет свободную ячейку, при необходимости добавляя строку. Сохранены loot-координаты `9000+`; при восстановлении старых координат ниже начальной сетки создаются недостающие строки.
- `git diff --check` выполнен. Поведение сохранения/загрузки отдельно не отмечалось пользователем как протестированное.
