#### Наблюдения
- `Assets/DarkTree FPS/Prefabs/GamePrefab.prefab` — YAML prefab размером около 2 МБ, около 1 974 объектов.
- Внутри находятся объекты персонажа/оружия и несколько UI-корней: `Canvas Main`, `Inventory Canvas`, `Mobile Input Canvas`, `Event System`.
- Есть UI-объекты здоровья/потребностей/боезапаса (`HealthSlider`, `HealthText`, `Hunger`, `Thirst`, `Stamina`, `AmmoText`), `Loot window`, `InfoPanel`, `Messages`, `Reticle`, а также сетка инвентаря.
- Обнаружены скрипты игрока (`Scripts/Player/FPSController.cs`, `PlayerStats.cs`, `UseObjects.cs`), оружия (`Scripts/Weapon/WeaponManager.cs`) и инвентаря (`Scripts/DT Inventory/Inventory/*`).
- В окружении отсутствует `rg`; для первичного поиска использованы `find` и `grep`.
- `PlayerStats` хранит сериализованные прямые ссылки на Health/Stamina/Hunger/Thirst UI; `DrawHealthStats()` обновлял эти элементы непосредственно.
- `Weapon.Start()` ищет `AmmoText` и `WeaponText` по имени; `UseObjects` ищет `UseCursor` и `UseButton`. Другие gameplay-скрипты также используют глобальный поиск компонентов.
- Сцена `Weapons.unity` содержит prefab instance `GamePrefab` и overrides; поэтому массовый перенос UI YAML сейчас рискован.
- `PlayerStats` и UI оставлены совместимыми через legacy-поля; добавлен отдельный presenter, который принимает состояние и обновляет UI.

- Пользователь прислал скриншоты: HUD отображается (здоровье/потребности внизу экрана, инвентарь и оружие видны).

- В Console также видны предупреждения Animator `State could not be found` и `Invalid Layer Index '-1'` из `StackWalker::GetCurrentCallstack`; их связь с этим исправлением не подтверждена.
